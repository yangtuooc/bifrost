## Overview

Alibaba Cloud is supported through Model Studio / DashScope APIs. Bifrost treats `aliyun` as a built-in provider with its own provider package. It reuses Bifrost's existing OpenAI wire-format handlers for operations whose request and response shapes are compatible, and uses provider-specific converters for Qwen-Image, Qwen-TTS, and Wan video because those APIs are not OpenAI wire-compatible.

The built-in default base URL is:

```text
https://dashscope.aliyuncs.com/compatible-mode/v1
```

For production workloads, Alibaba Cloud recommends workspace-specific regional base URLs such as:

```text
https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
```

### Supported Operations

| Operation | Bifrost support | Streaming | Upstream endpoint | Notes |
|-----------|-----------------|-----------|-------------------|-------|
| List Models | ✅ | - | `/models` | OpenAI-compatible model list format. |
| Text Completions | ✅ | ✅ | `/completions` | Uses Alibaba Cloud's OpenAI-compatible Completions API for models that expose classic text completion, such as Qwen Coder completion models. |
| Chat Completions | ✅ | ✅ | `/chat/completions` | Uses Alibaba Cloud's OpenAI-compatible Chat API. |
| Responses API | ✅ | ✅ | `/responses` | Uses Alibaba Cloud's OpenAI-compatible Responses API, not a Chat fallback. |
| Embeddings | ✅ | - | `/embeddings` | Uses OpenAI-compatible embedding request and response shape. |
| Image Generation | ✅ | ❌ | `/api/v1/services/aigc/multimodal-generation/generation` | Uses the Qwen-Image synchronous API. Bifrost converts `1024x1024` style sizes to Alibaba Cloud's `1024*1024` format. |
| Image Edit | ✅ | ❌ | `/api/v1/services/aigc/multimodal-generation/generation` | Uses Qwen-Image-Edit through Alibaba Cloud's native multimodal generation API. Bifrost sends input images as Base64 data URLs. |
| Speech (TTS) | ✅ | ✅ | `/api/v1/services/aigc/multimodal-generation/generation` | Uses Qwen-TTS through Alibaba Cloud's native multimodal generation API. Non-streaming responses download the returned audio URL; streaming responses decode Base64 audio chunks. |
| Transcription (STT) | ❌ | ❌ | - | Not enabled because Alibaba Cloud's documented speech recognition flows do not map cleanly to Bifrost's synchronous transcription abstraction in this provider. |
| Files | ✅ | - | `/files` | Uses Alibaba Cloud's OpenAI-compatible File API for upload, list, retrieve, delete, and content download. |
| Batch | ✅ | - | `/batches` | Uses Alibaba Cloud's OpenAI-compatible Batch File API. Inline `requests` are converted to JSONL and uploaded as a batch file. |
| Image Variation | ❌ | ❌ | - | Not documented as a distinct Qwen image variation API compatible with Bifrost's variation abstraction. |
| Count Tokens | ❌ | - | - | No Bifrost mapping is enabled for this provider. |
| Video Generation / Retrieve / Download | ✅ | - | `/api/v1/services/aigc/video-generation/video-synthesis`, `/api/v1/tasks/{task_id}` | Uses Alibaba Cloud's native asynchronous video task API and maps task lifecycle into Bifrost's Video API abstraction. List, delete, and remix are not enabled. |

<Note>
Bifrost appends OpenAI-compatible paths to the configured `network_config.base_url`. If you override the base URL, use the OpenAI-compatible base URL that includes `/compatible-mode/v1`. For Qwen-Image, Qwen-TTS, and video, Bifrost derives native `/api/v1/...` endpoints from the same host, so workspace-specific regional base URLs such as `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` are recommended for production.
</Note>

## Setup & Configuration

Configure Alibaba Cloud as a provider.

<Tabs>
<Tab title="Web UI">

1. Navigate to **Models** > **Model Providers**.
2. Click **Add New Provider** and select **Alibaba Cloud**.
3. Click **Add Key**.
4. Paste your DashScope API key directly or use an environment variable such as `env.DASHSCOPE_API_KEY`.
5. Set **Allowed Models** to `*` or to specific model IDs such as `qwen-plus`.
6. Save the provider configuration.

</Tab>
<Tab title="config.json">

```json
{
  "providers": {
    "aliyun": {
      "keys": [
        {
          "name": "aliyun-key-1",
          "value": "env.DASHSCOPE_API_KEY",
          "models": ["*"],
          "weight": 1.0
        }
      ]
    }
  }
}
```

</Tab>
<Tab title="Go SDK">

```go
case schemas.Aliyun:
    return []schemas.Key{{
        Name:   "aliyun-key-1",
        Value:  *schemas.NewEnvVar("env.DASHSCOPE_API_KEY"),
        Models: []string{"*"},
        Weight: 1.0,
    }}, nil
```

</Tab>
</Tabs>

## Chat Completions

Use the unified Bifrost endpoint with an `aliyun/<model>` model string:

```bash
curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aliyun/qwen-plus",
    "messages": [
      {"role": "user", "content": "Reply with exactly: aliyun ok"}
    ]
  }'
```

## Text Completions

Use Alibaba Cloud completion models through Bifrost's unified text completion endpoint:

```bash
curl -X POST http://localhost:8080/v1/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aliyun/qwen-coder-turbo",
    "prompt": "Write a Go function that returns true for even integers."
  }'
```

## Responses API

Use the same Bifrost Responses endpoint with an `aliyun/<model>` model string:

```bash
curl -X POST http://localhost:8080/v1/responses \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aliyun/qwen-plus",
    "input": "Reply with exactly: aliyun responses ok"
  }'
```

## Embeddings

Use Alibaba Cloud embedding models through Bifrost's unified embedding endpoint:

```bash
curl -X POST http://localhost:8080/v1/embeddings \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aliyun/text-embedding-v4",
    "input": "A short sentence to embed."
  }'
```

## Image Generation

Use Qwen-Image models through Bifrost's unified image generation endpoint:

```bash
curl -X POST http://localhost:8080/v1/images/generations \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aliyun/qwen-image-2.0-pro",
    "prompt": "A clean product sketch on a white background",
    "size": "1024x1024"
  }'
```

Alibaba Cloud's Qwen-Image API returns temporary image URLs. Bifrost maps those URLs into the standard `data[].url` field. `response_format=b64_json` is not produced by the upstream Qwen-Image synchronous API.

## Image Edit

Use Qwen-Image-Edit models through Bifrost's unified image edit endpoint:

```bash
curl -X POST http://localhost:8080/v1/images/edits \
  -F 'model=aliyun/qwen-image-edit' \
  -F 'prompt=Replace the background with a clean studio setting' \
  -F 'image=@input.png' \
  -F 'size=1024x1024'
```

Bifrost converts uploaded image bytes into Base64 data URLs for Alibaba Cloud's native multimodal generation API and maps returned image URLs into the standard `data[].url` field.

## Speech

Use Qwen-TTS models through Bifrost's unified speech endpoint:

```bash
curl -X POST http://localhost:8080/v1/audio/speech \
  -H "Content-Type: application/json" \
  --output speech.mp3 \
  -d '{
    "model": "aliyun/qwen3-tts-flash",
    "input": "Hello from Alibaba Cloud speech synthesis.",
    "voice": "Cherry",
    "language_code": "Chinese"
  }'
```

For streaming speech, request SSE output with `stream_format: "sse"`:

```bash
curl -N -X POST http://localhost:8080/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aliyun/qwen3-tts-flash",
    "input": "Stream this sentence as audio chunks.",
    "voice": "Cherry",
    "language_code": "Chinese",
    "stream_format": "sse"
  }'
```

Bifrost maps `voice` to Alibaba Cloud's native `input.voice` field and maps `language_code` to `input.language_type`. Additional provider parameters can be sent as top-level extra fields and are forwarded under Alibaba Cloud's `parameters` object.

## Video Generation

Use Wan video models through Bifrost's unified Video API. Bifrost creates an Alibaba Cloud asynchronous task and returns a provider-scoped Bifrost video ID in the `{task_id}:aliyun` format.

```bash
curl -X POST http://localhost:8080/v1/videos \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aliyun/wan2.7-t2v-2026-06-12",
    "prompt": "A compact product video on a clean white background",
    "seconds": "5",
    "size": "720p",
    "ratio": "16:9",
    "prompt_extend": true
  }'
```

Retrieve and download generated videos through Bifrost's standard Video endpoints:

```bash
curl "http://localhost:8080/v1/videos/{task_id}:aliyun"
curl "http://localhost:8080/v1/videos/{task_id}:aliyun/content" --output output.mp4
```

Bifrost maps Alibaba Cloud task statuses to Bifrost video statuses and maps completed task `video_url` values into `videos[].url`. Failed tasks are returned as video responses with `status: "failed"` and an `error` payload. Video list, delete, and remix return `unsupported_operation`.

## Files

Upload files through Bifrost's unified Files API. For Alibaba Cloud document extraction, use provider-supported purposes such as `file-extract`; for Batch, use `batch`.

```bash
curl -X POST http://localhost:8080/v1/files \
  -H "Content-Type: multipart/form-data" \
  -F 'provider=aliyun' \
  -F 'purpose=batch' \
  -F 'file=@requests.jsonl'
```

## Batch

Create a file-based Batch job after uploading a JSONL input file:

```bash
curl -X POST http://localhost:8080/v1/batches \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "aliyun",
    "input_file_id": "file-batch-xxx",
    "endpoint": "/v1/chat/completions",
    "completion_window": "24h"
  }'
```

## Streaming

Streaming uses the same OpenAI-compatible SSE format:

```bash
curl -N -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aliyun/qwen-plus",
    "stream": true,
    "messages": [
      {"role": "user", "content": "Write one short sentence."}
    ]
  }'
```

## Capability Boundary

Unsupported operations return Bifrost's standard `unsupported_operation` error. This is intentional for capabilities that are not documented by Alibaba Cloud, or do not map cleanly to Bifrost's current provider abstraction. For Alibaba Cloud, Qwen-Image, Qwen-TTS, and video are implemented with provider-specific native API converters; STT, image variation, count tokens, video list, video delete, and video remix remain unsupported in this provider.
