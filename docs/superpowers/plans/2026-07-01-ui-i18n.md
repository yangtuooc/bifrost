# UI 国际化实施计划

> **给 agentic workers 的要求：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 按任务逐项执行本计划。步骤使用 checkbox（`- [ ]`）语法便于跟踪。

**目标：** 让 Bifrost UI 支持 English / 中文切换，默认保持 English 体验不变，并保留现有 API 名称、Provider 标识、路由和测试选择器。

**架构：** 使用标准生态库 `i18next`、`react-i18next` 和 `i18next-browser-languagedetector` 接入国际化能力。翻译资源以静态 bundle 的 locale module 形式放在 `ui/lib/i18n/locales` 下，在 `ui/app/main.tsx` 中一次性初始化 i18next，UI 组件直接使用 `useTranslation()`。sidebar 的稳定 `data-testid` 必须与翻译后的展示文案解耦，使用稳定 item ID 作为测试标识来源。

**技术栈：** Vite、React 19、TypeScript、TanStack Router、i18next、react-i18next、i18next-browser-languagedetector、本地 shadcn 风格 UI 组件。

### 任务 2：添加 i18next 基础设施

**文件：**
- 新增：`ui/lib/i18n/locales/en.ts`
- 新增：`ui/lib/i18n/locales/zh.ts`
- 新增：`ui/lib/i18n/i18n.ts`
- 修改：`ui/app/main.tsx`

- [x] **步骤 1：创建 locale modules**

创建英文和中文资源，key 按模块分组：

```ts
export const en = {
	common: {
		actions: {
			cancel: "Cancel",
			continue: "Continue",
			delete: "Delete",
			edit: "Edit",
		},
	},
} as const;
```

中文资源必须保留技术标识原文，例如 `API Key`、`MCP`、`Provider ID`、`OpenAI` 和 `config.json`。

- [x] **步骤 2：初始化 i18next**

创建 `ui/lib/i18n/i18n.ts`，使用 `initReactI18next` 和 `LanguageDetector`，配置 `fallbackLng: "en"`、`supportedLngs: ["en", "zh"]`、`load: "languageOnly"`、`interpolation.escapeValue: false`、`react.useSuspense: false`。

- [x] **步骤 3：全局只初始化一次**

在 `ui/app/main.tsx` 中、渲染 `RouterProvider` 前引入 `@/lib/i18n/i18n`。
